# Skill: Generate Persuasive Ebooks

Pipeline completo para escrever e-books de qualquer tema com persuasão de nível
avançado, baseada em neurociência, psicologia comportamental e estrutura de best-sellers.

## Referências internas

- Para pedidos de e-books cristãos, didáticos, pastorais ou voltados ao público geral,
  leia `references/christian-ebook-models.md` antes de montar o sumário.
- Use essa referência para reproduzir a cadência editorial dos 4 modelos anexados:
  abertura confessional, 8 capítulos, eixo bíblico + aplicação prática, linguagem
  acessível e fechamento com chamado pastoral sem tom comercial agressivo.
- A mesma referência também define padrões de título, subtítulo, forma das frases,
  abertura de capítulos, tom, voz e integração entre Bíblia, psicologia e ciência.
- Para pedidos no padrão editorial do Pr. Filipe Ivo Pereira, aplique também:
  fórmulas de título e subtítulo, capítulo final com proposta prática, segmentação
  para membros/líderes/pastores, loops abertos, formatação `.docx` e bloco final
  "Sobre o Autor" descritos na referência.

## FASE 0 — COLETA DE INSUMOS (sempre executar antes de escrever)

Antes de iniciar, confirme com o usuário os seguintes dados. Se algum já estiver no
contexto, não pergunte de novo.

```
DADOS OBRIGATÓRIOS:
1. Tema / título provisório do e-book
2. Público-alvo (quem vai ler — dor, desejo, nível de consciência)
3. Oferta ou produto que o e-book vai posicionar (mesmo que implicitamente)
4. Tom desejado: mais didático / mais narrativo / mais provocador
5. Tamanho: curto (10–20 páginas) / médio (20–40 páginas) / longo (40–80 páginas)
6. Meta mínima de palavras quando aplicável: para livros completos, use 10.000 palavras
   como piso padrão, salvo se o usuário pedir explicitamente outro tamanho

DADOS OPCIONAIS (enriquecem muito o resultado):
- Crenças falsas do público que precisam ser quebradas
- Principais objeções que o leitor teria para aceitar a solução
- Transformação específica que o leitor deve sentir ao terminar
- Concorrentes ou abordagens anteriores que não funcionaram para esse público
- Se é um ebook cristão: doutrina-base, textos bíblicos centrais e tradição desejada
```

## FASE 1 — ARQUITETURA ESTRATÉGICA

Antes de escrever uma palavra do e-book, monte a arquitetura interna:

### 1.1 — Mapeamento dos Três Cérebros

Para cada capítulo, identifique o que ativa cada camada:

**Reptiliano (sobrevivência / decisão rápida):**
- Qual é o risco implícito de não ler / não agir?
- Qual é o ganho de status ou poder que o leitor vai sentir?
- Existe urgência implícita? (não manipulação — mas custo real do tempo perdido)

**Sistema Límbico (emoção / conexão):**
- Qual história real ou plausível abre identificação imediata?
- Qual conflito interno o leitor carrega silenciosamente?
- Qual frustração ele sente, mas nunca verbalizou?

**Neocórtex (lógica / justificativa):**
- Qual argumento racional sustenta a decisão emocional?
- Qual sequência causa → efeito → solução organiza o capítulo?
- Quais dados, estudos ou analogias validam a proposta?

### 1.2 — Arco Narrativo Global (Hook → Tensão → Revelação → Transformação)

O e-book inteiro deve seguir um arco único:

```
HOOK (Capítulo 1):
  → Identificação imediata com o problema
  → Conflito interno nomeado
  → Loop aberto que não se fecha

TENSÃO (Capítulo 2):
  → Revelação da causa raiz que o leitor desconhecia
  → Quebra de crenças anteriores
  → Momento AHA: "agora tudo faz sentido"

REVELAÇÃO (Capítulo 3 ou meio do livro):
  → Nova lógica / novo modelo mental
  → Reposicionamento de identidade
  → O leitor começa a se ver de outro jeito

TRANSFORMAÇÃO (Capítulo final):
  → O custo invisível de continuar igual
  → O caminho acessível (mesmo que parcial)
  → Convite implícito à ação (sem parecer venda)
```

### 1.3 — Sumário Estratégico

Monte um sumário com 3 a 6 capítulos, cada um com:
- Título (deve gerar curiosidade ou tensão imediata)
- Objetivo neurocientífico do capítulo
- Emoção-alvo que o leitor deve sentir ao terminar

Se o pedido for cristão e didático, use como padrão preferencial:
- Introdução confessional ou pastoral antes do capítulo 1
- 8 capítulos
- Capítulo 5 dedicado ao que a Bíblia realmente diz sobre o tema
- 1 capítulo de diagnóstico do erro da igreja ou do modelo mental do leitor
- 1 capítulo com framework prático numerado
- Capítulo 7 com aplicação específica para membros, líderes e pastores
- Fechamento pastoral e gracioso

Para ebooks cristãos longos, priorize aproximadamente 80 páginas finais em `.docx`,
com capítulos equilibrados e sem aparência de apostila.
Para livros completos, trate 10.000 palavras como mínimo operacional padrão.

## FASE 2 — ESCRITA CAPÍTULO POR CAPÍTULO

### Estrutura Interna de Cada Capítulo

**ABERTURA (primeiros 2 parágrafos):**
- Comece com uma cena, pensamento ou situação que o público reconhece instantaneamente
- Efeito "isso é sobre mim" obrigatório
- Não comece com definição, dado ou contexto histórico

**DESENVOLVIMENTO:**
- Mostre o conflito interno invisível
- Nomeie o que o leitor sente mas nunca soube articular
- Crie tensão emocional crescente sem ser agressivo
- Use analogias simples e poderosas (uma boa analogia vale 10 parágrafos de explicação)

**VIRADA:**
- Introduza o insight ou modelo mental novo
- O leitor deve sentir: "nunca tinha pensado assim, mas faz todo sentido"
- Use a sequência: crença anterior → por que ela está errada → nova perspectiva

**FECHAMENTO DO CAPÍTULO:**
- Não resolva tudo — deixe um loop aberto que puxa para o próximo capítulo
- Ou: termine com uma pergunta que o leitor vai carregar

**EXCEÇÃO (último capítulo):**
- Feche todos os loops abertos
- Mostre o custo real de não agir
- Crie sensação de oportunidade acessível agora
- Termine com convite implícito à ação (não CTA agressivo)

Para ebooks cristãos:
- Abra cada capítulo com uma epígrafe bíblica curta e pertinente
- Faça exegese pastoral leve, suficiente para sustentar a aplicação sem soar acadêmico
- Evite moralismo; conduza o leitor de diagnóstico para graça, prática e esperança
- Preserve o tom de conversa de púlpito para pessoa comum, não de tratado teológico
- Use de 3 a 5 subheadings internos por capítulo
- Nos capítulos 1 a 7, feche com um loop aberto, pergunta carregável ou transição forte
  para o próximo capítulo
- No capítulo 7, diferencie explicitamente aplicação para membros, líderes e pastores

## FASE 3 — CAMADAS DE PERSUASÃO AVANÇADA

Aplique estas técnicas durante toda a escrita:

### 3.1 — Amplificação de Dor Latente (sem parecer manipulação)
- Nomeie a dor com precisão cirúrgica antes de oferecer qualquer solução
- Use linguagem que o leitor usaria para si mesmo, não jargão técnico
- Evite hipérboles — precisão é mais poderosa que intensidade

### 3.2 — Quebra de Crenças do Mercado
- Identifique as 2 ou 3 crenças mais comuns do nicho
- Quebre cada uma com lógica + emoção + dados (nessa ordem)
- Mostre por que as abordagens anteriores do leitor não funcionaram
  (sem atacar concorrentes — atacando o sistema ou a crença)

### 3.3 — Reposicionamento de Identidade
- O leitor não deve terminar o e-book se sentindo instruído
- Ele deve terminar se sentindo diferente — como alguém que "já entendeu"
- Use frases que reforcem essa nova identidade: "pessoas que entendem isso...",
  "quem vê dessa forma...", "a partir desse ponto você..."

### 3.4 — Posicionamento de Solução Inevitável
- Nunca venda diretamente no e-book
- Construa o cenário onde a solução se torna a conclusão lógica e natural
- O leitor deve chegar à solução por conta própria, conduzido pela narrativa

### 3.5 — Princípios de Cialdini Integrados
- **Reciprocidade**: entregue valor real antes de qualquer pedido
- **Autoridade**: use dados, estudos, experiências reais com naturalidade
- **Prova social**: "a maioria das pessoas que enfrenta isso..."
- **Escassez**: custo do tempo — não urgência falsa
- **Comprometimento**: faça o leitor concordar com premissas pequenas antes das grandes

## FASE 4 — TOM E ESTILO DE ESCRITA

### Regras de Ouro

1. **Escreva em formato de livro, não de post.** Parágrafos fluídos, sem fragmentação
   excessiva, sem listas onde deveria ter prosa.

2. **Cada parágrafo deve ganhar o direito ao próximo.** O leitor não pode parar.
   Use ganchos de final de parágrafo constantemente.

3. **Varie o ritmo.** Alterne parágrafos longos (desenvolvimento) com frases curtas
   (impacto). A mudança de ritmo cria tensão e atenção.

4. **Nunca use jargão técnico sem tradução imediata.** Se precisar de um termo, explique
   em seguida com uma analogia do cotidiano.

5. **Confissão antes de autoridade.** Antes de ensinar, mostre uma vulnerabilidade real
   ou reconheça que o leitor pode estar cético. Isso cria confiança antes da persuasão.

6. **A solução é sempre lógica depois da emoção.** Nunca comece pelo argumento racional.
   Primeiro a emoção, depois a lógica que a justifica.

7. **Para público cristão, escreva como quem aconselha e ensina ao mesmo tempo.**
   O texto deve soar bíblico, caloroso, acessível e confiável para leitores comuns.

### Calibração por Tom

**Tom Didático:** mais explicações, mais dados, mais passo a passo. Analogias frequentes.
Leitor quer entender o "como". Linguagem clara e direta.

**Tom Narrativo:** mais histórias, mais cenas, mais personagens. Leitor se projeta
em situações. Use diálogos internos ("você já se perguntou por que...").

**Tom Provocador:** questione crenças desde o título. Use paradoxos e afirmações
contraintuitivas. Leitor quer ser desafiado. Cuidado: provocar sem arrogância.

## FASE 5 — TÍTULOS E SUBTÍTULOS

### Fórmulas de Títulos de Alto Impacto

```
"O que [autoridade / maioria] nunca te contou sobre [tema]"
"Por que você [ação comum] e ainda assim [resultado frustrante]"
"O erro silencioso que [público-alvo] começa a cometer"
"[Número] anos fazendo [coisa] antes de entender isso"
"A pergunta que muda tudo sobre [tema]"
"Como [transformação desejável] sem [sacrifício que o leitor teme]"
```

### Subtítulos de Capítulo

Cada subtítulo interno deve:
- Criar curiosidade (o leitor quer saber o que vem)
- Ou criar tensão (o leitor reconhece o problema nomeado)
- Nunca ser apenas descritivo ("O conceito de X")

Para ebooks cristãos, favoreça subtítulos neste espírito:
- "O que a Bíblia realmente diz sobre..."
- "As mentiras que a igreja acidentalmente ensinou sobre..."
- "Por que você ainda..."
- "A vida que começa quando..."

Para títulos e subtítulos de ebooks cristãos no padrão dos modelos, favoreça:
- "A [coisa ruim] que você não precisa carregar"
- "A [coisa boa] que você ainda não teve"
- "O [recurso] que você tem é o suficiente"
- "Você é o que você [verbo de hábito]"
- Subtítulo na linha de "Um guia bíblico e prático para..." com benefício claro

## FASE 6 — REVISÃO FINAL (checklist antes de entregar)

Antes de finalizar, verifique:

- [ ] O primeiro parágrafo gera efeito "isso é sobre mim" imediato?
- [ ] Cada capítulo ativa os três cérebros (reptiliano, límbico, neocórtex)?
- [ ] A dor foi amplificada antes de qualquer solução ser apresentada?
- [ ] Pelo menos uma crença comum do nicho foi quebrada com elegância?
- [ ] O leitor se reposiciona de identidade ao longo do livro?
- [ ] A solução aparece como conclusão natural — não como venda?
- [ ] O último capítulo fecha todos os loops abertos?
- [ ] O tom é consistente do começo ao fim?
- [ ] Há variação de ritmo nos parágrafos?
- [ ] Nenhum capítulo começa com definição, dado ou contexto histórico?
- [ ] Se o ebook for cristão, o texto sustenta a aplicação com Bíblia sem soar moralista?
- [ ] Se o ebook seguir os modelos de referência, há introdução + 8 capítulos + fechamento pastoral?

  finais, salvo se o usuário pedir outro tamanho.
- No padrão cristão do Pr. Filipe Ivo Pereira, inclua ao final um bloco "Sobre o Autor"
  consistente com a identidade pastoral e de comunicação do autor.
