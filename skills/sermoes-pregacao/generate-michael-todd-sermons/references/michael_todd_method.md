# Michael Todd Sermon Method

Use this reference when the user wants a sermon built around Michael Todd's authentic style, with alliterative points, youth-aware language, Black church participation, extended analogies, and prophetic faith-building ending.

## Core Identity

Michael Todd blends:

- Black church tradition
- hip-hop and pop-culture fluency
- autobiographical vulnerability
- practical teaching
- energetic performance

The audience often includes:

- younger adults
- people carrying trauma
- people suspicious of traditional church culture
- online viewers
- multi-ethnic listeners

## Central Principle

Progression, not perfection.

Every application should point to the next step, not impossible final arrival.

## Structural Reality

The sermon is not built around abstract acts. It is built around 3 to 5 numbered points with alliterative or strongly parallel titles.

Each point should contain:

1. a numbered title
2. an extended everyday analogy
3. biblical support
4. direct application
5. audience participation

## Title and Series

Create:

- a series name that feels like a cultural product
- a sermon title with dual structure:
  - provocative main title
  - contextual subtitle

## Extended Analogy

This is a primary teaching tool.

Choose a familiar object, system, or daily-life scenario and develop it long enough to hold tension before making the spiritual turn explicit.

## Call-and-Response

Mark congregational engagement explicitly in the written sermon.

Examples:

- `[CONGREGACAO REPETE]`
- `[PARTICIPACAO ONLINE]`
- `[PAUSA]`
- `[OLHA PARA A CAMERA]`

## Pop-Culture Use

Use at least one cultural reference per point when it naturally clarifies the meaning.

It may include:

- music culture
- social media language
- sports
- reality television
- current online behavior

Do not use culture as decoration only. It must illuminate the truth.

## HHOT

Use HHOT moments where the sermon invites vulnerability:

- hot
- humble
- open
- transparent

## Vulnerability Standard

The opening should often include:

- recent story
- real names or details when appropriate
- awkwardness, fear, shame, or confusion
- personal stakes

The vulnerability should feel risky enough to create trust.

## Translation Style

The sermon may move across multiple translations if that serves the point:

- NLT
- NIV
- AMP
- The Message
- KJV

Explain why a given rendering matters when switching.

## Full Sermon Flow

### Opening

- acknowledge the in-person and online audience
- tell a recent autobiographical story
- connect to the series
- pose the key question
- introduce the main text

### Point 1

- announce the point
- `write this down`
- build the analogy
- anchor it in Scripture
- apply it personally
- activate participation

### Point 2

Repeat the structure with increased intensity.

### Point 3

Repeat the structure, often with deeper vulnerability and the sermon's most central text.

### Visual Climax

Use only when the message naturally supports an object-based moment.

### Ending

- rapid recap
- final question
- prophetic declaration
- `one day` style faith language
- congregational repeated declaration
- one immediate next step
- prayer as proclamation

## Default Deliverable

Unless the user requests a different format, produce:

1. Pre-sermon declaration with the five required statements.
2. Complete sermon manuscript.
3. One clear immediate next step.
4. A formatted `.docx` file that passes the minimum word count threshold.

## Word Document Requirement

- The standard output is a Microsoft Word `.docx` document.
- For a complete sermon, enforce at least 7,500 words unless the user explicitly changes the requirement.
- Build the manuscript first, then convert it to `.docx`.
- Confirm the final word count before treating the job as complete.
