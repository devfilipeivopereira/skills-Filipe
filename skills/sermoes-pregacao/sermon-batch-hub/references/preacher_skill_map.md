## Special cases

- `all` means all installed `generate-*-sermons` skills in the batch hub order.
- `Bob Smiley` is not part of the default sermon batch because it is a message-preparation skill, not a standard sermon generator. Include it only if the user explicitly asks.
- `generate-high-impact-preaching-series` is not a sermon generator and should not be included in sermon batches.
