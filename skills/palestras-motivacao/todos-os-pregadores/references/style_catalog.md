# Style Catalog

Use this catalog to resolve user requests to embedded methods. Paths are relative to the `todos-os-pregadores` skill folder.

## Default All Policy

- Biblical reference, sermon, preaching, culto, mensagem, or esboco biblico: use the sermon/preacher styles.
- Palestra, keynote, treinamento, lideranca, motivacional, carreira, produtividade, or comunicacao: use the talk/speaker styles.
- `todos os pregadores e palestrantes`: use both sermon/preacher and talk/speaker styles.
- Helper/hub skills are loaded for guidance but do not receive duplicate output files unless the user explicitly asks.

## Output Slugs

Use lowercase ASCII slugs for file names:

- Replace spaces with hyphens.
- Remove accents and punctuation.
- Keep initials readable, e.g. `td-jakes`, `ed-young-jr`, `paul-scott-wilson`.
- Use `source_slug__style_slug.md`, for example `joao-9__rick-warren.md`.
