# Rick Blackwood Multisensory Preaching Method

Use this file as the governing reference when generating sermons in Rick Blackwood's style.

## Core Conviction

Faithful exposition and multisensory communication belong together. The Bible remains the non-negotiable content, but the preacher should use multiple channels so the hearer becomes a doer.

Formula:

- hear
- see
- interact

This produces stronger:

- attention
- comprehension
- retention
- obedience

## The Three Channels

### 1. Auditory

Already present in preaching, but it must be refined through:

- clear verbal explanation
- descriptive language
- deliberate repetition
- varied pace and pauses

### 2. Visual

Use:

- props
- projected images or short videos
- staging or room environment
- thematic objects already visible before the sermon starts

Visual elements must serve the biblical point, not overshadow it.

### 3. Interaction

Use:

- listening guide fill-ins
- spoken repetition
- brief neighbor interaction
- pauses for response
- written weekly commitment

The hearer must do something with the truth, not only hear about it.

## The Big Idea

Every sermon must have one Big Idea:

- one full sentence
- easy to repeat
- clear to an ordinary hearer
- tied directly to the text
- actionable in life

Announce it early. Do not hide it until the end.

## The Listening Guide

The listening guide is not a printed slide deck. It is an interactive learning tool.

It should include:

- fill-in blanks for the Big Idea and major points
- reflection or application prompts
- a final action commitment

The listener should be writing during the sermon.

## The Surprise Element

A surprise element may create a memory peak, but only if it anchors truth.

Bad surprise:

- spectacle remembered without the sermon truth

Good surprise:

- sensory moment that permanently attaches the truth to a memorable image or action

## The Eight Phases

### Phase 0

Pre-sermon sensory environment already in place.

### Phase 1

Opening that captures attention through prop, video, or concrete situation.

### Phase 2

Big Idea announced early.

### Phase 3

Verse-by-verse exposition, each main point reinforced sensorially.

### Phase 4

Illustrations that create experience, not just narration.

### Phase 5

Surprise element.

### Phase 6

Concrete application for the coming week.

### Phase 7

Congregational interaction throughout.

### Phase 8

Closing review of the Big Idea across multiple channels and a written-spoken-prayed call to action.

## Final Diagnostic

Before finishing, verify:

- the text still leads
- the Big Idea is memorable
- sensory elements are tied to truth
- the congregation is active, not passive
- the final application is clear enough to do this week
