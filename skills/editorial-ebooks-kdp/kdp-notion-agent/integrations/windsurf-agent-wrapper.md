# Windsurf Agent Wrapper

## Função

Fazer o Windsurf usar `kdp-notion-agent` como agente de publicação editorial completo.

## Comportamento esperado

- acionar automaticamente `kdp-notion-agent` em pedidos de ebook KDP via Notion
- tratar a skill como agente operacional e não como prompt isolado
- preservar o padrão fixo do pipeline

## Frase de acionamento sugerida

`Use kdp-notion-agent e processe o sermão <nome> no Notion até publicar o rascunho revisável.`
